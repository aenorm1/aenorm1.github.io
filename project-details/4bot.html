4BOT

While working at the NEIDL, I was involved in developing an AI for inventory management that can store and retrieve the locations of laboratory items upon asking it while also having similar chatGPT like functionalities such as having being able to compute simple mathematical equations and maintaining general conversations. As for the application, I used the OpenAI API to create the AI and node.JS along with JavaScript to create the funtionalities. For the user interface, I used CSS and HTML. For the database, I used MongoDB.
